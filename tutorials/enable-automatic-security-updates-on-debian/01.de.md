## Einleitung

Regelmäßige Sicherheitsupdates sind eine der wichtigsten Grundlagen für einen sicheren Serverbetrieb. In der Praxis werden Updates jedoch oft vergessen, besonders bei kleineren Projekten oder Testsystemen.

In diesem Tutorial richtest du auf einem Debian-Server `unattended-upgrades` ein. Dadurch werden Sicherheitsupdates automatisch installiert, ohne dass du jeden Tag manuell `apt upgrade` ausführen musst. Zusätzlich prüfst du am Ende, ob die Konfiguration wie erwartet funktioniert.

### Was du am Ende hast

- Automatische Sicherheitsupdates über `unattended-upgrades`
- Tägliche Paketlisten-Aktualisierung über APT-Periodics
- Eine getestete Konfiguration inklusive Log-Prüfung

**Voraussetzungen**

| Voraussetzung | Beschreibung |
|---|---|
| Server | 1 Debian-Server (z. B. ein Cloud-Server) |
| Zugriff | Benutzer mit `sudo`-Rechten oder direkter Root-Zugriff |
| Kenntnisse | Grundlegende Erfahrung mit der Shell |

## Schritt 1 - Server aktualisieren und Paket installieren

Aktualisiere zuerst die Paketlisten und installiere dann die benötigten Pakete:

```bash
sudo apt update
sudo apt upgrade -y
sudo apt install unattended-upgrades apt-listchanges -y
```

Die Pakete haben folgende Aufgaben:

- `unattended-upgrades`: installiert Updates automatisch
- `apt-listchanges`: zeigt wichtige Paket-Änderungen (z. B. News, Changelog) bei Updates an

Prüfe danach, ob das Paket vorhanden ist:

```bash
dpkg -l unattended-upgrades
```

## Schritt 2 - Sicherheitsquellen für automatische Updates festlegen

Die Datei `/etc/apt/apt.conf.d/50unattended-upgrades` steuert, aus welchen APT-Quellen automatisch installiert wird.

Oeffne die Datei:

```bash
sudo nano /etc/apt/apt.conf.d/50unattended-upgrades
```

Stelle sicher, dass mindestens folgende `Allowed-Origins` enthalten und nicht auskommentiert sind:

```bash
Unattended-Upgrade::Allowed-Origins {
        "${distro_id}:${distro_codename}-security";
        "${distro_id}:${distro_codename}-updates";
};
```

Mit dieser Konfiguration installiert Debian automatisch Sicherheitsupdates und reguläre Paket-Updates aus den offiziellen Debian-Repositories.

> **Hinweis:** Wenn du nur Sicherheitsupdates automatisch installieren willst, lasse nur `-security` aktiv.

Speichere die Datei und schließe den Editor.

## Schritt 3 - Automatische Ausführung aktivieren

Jetzt aktivierst du die periodische Ausführung von APT und `unattended-upgrades`.

Oeffne die Datei:

```bash
sudo nano /etc/apt/apt.conf.d/20auto-upgrades
```

Trage folgenden Inhalt ein:

```bash
APT::Periodic::Update-Package-Lists "1";
APT::Periodic::Unattended-Upgrade "1";
```

Bedeutung:

- `Update-Package-Lists "1"`: aktualisiert täglich die Paketlisten
- `Unattended-Upgrade "1"`: führt täglich automatische Updates aus

Optional kannst du zusätzlich alte Paketdateien automatisch bereinigen:

```bash
APT::Periodic::AutocleanInterval "7";
```

Damit werden heruntergeladene, nicht mehr benötigte Pakete alle 7 Tage aufgeräumt.

> **Tipp:** Für produktive Systeme ist ein täglicher Lauf sinnvoll. Auf Testsystemen reicht oft ebenfalls diese Standardeinstellung.

## Schritt 4 - Konfiguration testen

Bevor du dich auf den Automatismus verlässt, teste die Konfiguration mit einem Dry-Run:

```bash
sudo unattended-upgrade --dry-run --debug
```

In der Ausgabe solltest du sehen, welche Quellen verwendet werden und welche Pakete verarbeitet würden.

<details>
<summary>Beispiel: typische Dry-Run-Hinweise</summary>

```shellsession
Checking if system is running on battery is skipped. Please install powermgmt-base package to check power status and skip installing updates when the system is running on battery.
Starting unattended upgrades script
Allowed origins are: ...-security, ...-updates
No packages found that can be upgraded unattended
```

</details>

Wenn keine Fehler erscheinen, kannst du einen echten Lauf starten:

```bash
sudo unattended-upgrade --debug
```

## Schritt 5 - Logs und Status prüfen

Die wichtigsten Logdateien sind:

- `/var/log/unattended-upgrades/unattended-upgrades.log`
- `/var/log/unattended-upgrades/unattended-upgrades-dpkg.log`

Zeige die letzten Zeilen an:

```bash
sudo tail -n 50 /var/log/unattended-upgrades/unattended-upgrades.log
sudo tail -n 50 /var/log/unattended-upgrades/unattended-upgrades-dpkg.log
```

Du kannst auch prüfen, ob der systemd-Timer aktiv ist:

```bash
systemctl list-timers --all | grep apt
```

Wenn hier ein nächster Lauf für `apt-daily.timer` und `apt-daily-upgrade.timer` angezeigt wird, ist die automatische Ausführung aktiv.

> **Wichtig:** Wenn keine Timer angezeigt werden, prüfe, ob `systemd`-Timer auf dem System deaktiviert wurden oder ob ein minimales Container-Image ohne Timer-Konfiguration verwendet wird.

## Schritt 6 - Optional: Verhalten bei notwendigem Reboot anpassen

Einige Sicherheitsupdates (z. B. fuer Kernel oder zentrale Bibliotheken) erfordern einen Neustart. Das Verhalten konfigurierst du ebenfalls in `/etc/apt/apt.conf.d/50unattended-upgrades`.

Beispiele:

```bash
Unattended-Upgrade::Automatic-Reboot "false";
Unattended-Upgrade::Automatic-Reboot-Time "03:30";
```

- Mit `false` wird nie automatisch neugestartet.
- Mit `true` wird bei Bedarf automatisch neugestartet, zur konfigurierten Uhrzeit.

Plane diese Einstellung sorgfältig, damit produktive Dienste nicht unerwartet unterbrochen werden.

## Ergebnis

Du hast auf Debian automatische Sicherheitsupdates mit `unattended-upgrades` eingerichtet, die periodische Ausführung aktiviert und die Konfiguration getestet. Damit reduzierst du das Risiko, kritische Sicherheitspatches zu verpassen.

Für produktive Umgebungen empfiehlt es sich zusätzlich, Monitoring und Benachrichtigungen einzurichten, damit Update-Fehler schnell auffallen.

**Kurze Checkliste zum Abschluss:**

- [x] `unattended-upgrades` ist installiert
- [x] `Allowed-Origins` sind passend gesetzt
- [x] `20auto-upgrades` ist aktiviert
- [x] Dry-Run wurde ohne Fehler ausgeführt
- [x] Timer und Logs wurden geprüft
